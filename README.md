📋 Descripción del Proyecto
FindLink Backend es una API REST desarrollada con NestJS que permite a los usuarios crear perfiles tipo LinkTree personalizables. Los usuarios pueden agregar múltiples enlaces, crear temas personalizados o seleccionar temas prediseñados, y compartir su perfil único. La plataforma incluye funcionalidades de búsqueda para descubrir perfiles de otros usuarios.
